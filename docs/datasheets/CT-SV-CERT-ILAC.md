## What you get

A calibration certificate for your specific target, issued by a CNAS-accredited laboratory (CNAS is a signatory to the ILAC MRA, so the certificate is recognised worldwide). The certificate states measured feature positions, flatness, measurement uncertainty and traceability to national standards. It is the document auditors ask for under ISO 9001 / IATF 16949 / ISO 17025 quality systems.

This is different from the inspection report included with every target: the inspection report is issued by Calib.Tools from our own measurements; the certificate is independent and accredited.

## Scope

| | |
|---|---|
| Applies to | Any Calib.Tools planar target; recommended for ceramic and glass, available for composite |
| Measured | Pattern feature positions (all corners, or a defined subset for large boards), flatness, overall dimensions |
| Uncertainty (typical) | Ceramic/glass: U = 1–2 µm (k = 2) · Composite: U = 10–20 µm (k = 2); stated per certificate |
| Reference temperature | 20 °C |
| Deliverable | PDF certificate with laboratory accreditation mark; measured coordinates CSV; our cover note CT-CC-<serial> linking certificate to serial number |
| Lead time | Adds 1–3 weeks to delivery (board is measured before shipping) |
| Validity | Certificates carry no expiry; recommended recalibration interval is stated (typically 24 months for composite, 36–60 months for ceramic/glass depending on use) |

## How to order

Add the ILAC-MRA certificate on the product page when buying a target, or order SVC-X-CERT-ILAC separately for a target you already own (return shipping both ways is on you; we handle the laboratory).

## Recalibration

SVC-X-RECAL: the same measurement on a target you already have, with a new certificate. Ask for a quote with the serial number.

## Notes

- Laboratory and accreditation body are named on the certificate. Calib.Tools does not issue accredited certificates itself.
- Certificates are issued to the serial number, not to the buyer; they stay with the board if it changes hands.
- Price shown on the product page covers one target up to 400 × 300 mm; larger boards are quoted.
