# Design direction A

Source: Claude Design canvas "calib.tools Landing Page" (artboards: Home desktop, Home mobile,
Product page, Pattern generator, Guide article).

- Palette: brand #E60012, brand-dark #B3000E, brand-tint #FBE9EA; ink #1A1A1A / #4A4A4A / #6B6B6B;
  lines #E6E6E6 / #ECECEC; grounds #FFFFFF / #FAFAFA / #F5F5F5. Dark band uses ink with brand top rules.
- Type: Inter (400–800) for UI/body, JetBrains Mono 500 for eyebrows, specs and file names.
- Tagline: "Calibrate with confidence." Secondary lines: "Free tools. Serious targets.",
  "From checkerboard to certificate.", "Built flat. Measured twice. Shipped fast.", "Where calibration starts."
- Logo: 3×3 red/black square grid + wordmark `calib.tools` (keep as one word, red ".tools").
- Tables: header row brand-tint background with brand-dark text (never white text on red).
