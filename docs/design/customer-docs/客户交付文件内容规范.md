# Calib.Tools · 客户交付文件内容规范（v1，2026-10-26）

> **2026-10-26 修订**：主体为美国公司、货从中国工厂直发欧洲、收款走美国主体；暂不提 Munich；网站/数据表/CoC/报告不标产地（只在海关文件写）；章环字去掉 MUNICH、转角 −6°；报告 Location 写 "per Calib.Tools procedure CT-WI-001"；可追溯性 = 对照 DAkkS 校准的 golden sample 比对测量。下文与此冲突处以本条为准，详见 06/决策记录 2026-10-26 01:55–02:12。

目的：列出我们现在和将来交给客户的**每一份文件**的内容、字段、顺序、数据来源和措辞规则，供版式设计用。先定内容，再设计样式。

语言：英文为准（德语版后做）。纸张：A4 竖版为主；美国客户同内容出 Letter。

## 2. CT-IR · 检验报告（每块板）

**目的**：证明这一块板出厂前按图纸测过；给工程师实测数据；给采购一份可归档的记录。
**触发**：每个序列号出厂前；数据来自 `data/serials.json` + `data/measurements/<sn>.json`；无测量数据时显示 PENDING，不填样例数。

### 第 1 页

| 区块 | 字段 | 来源 / 规则 |
|---|---|---|
| 标识 | Part number · Description · Serial number · Lot · Datasheet (code + rev) · Pattern (summary) · Marker ID range · Start ID | serials.json；Description 由型号推出（家族 + 材质），陶瓷不出现 composite |
| 检验信息 | Inspection date · Inspector (initials) · Location · Instrument (type, ID, last calibration date) · Ambient temperature (°C) · Reference temperature 20 °C | Location 写 "per Calib.Tools procedure CT-WI-001"（2026-10-26 定）；Traceability 写 golden sample 的 DAkkS 证书号与有效期 |
| 结果 | Overall result PASS / FAIL / PENDING；一句话 `All measured features within datasheet tolerance.` 或列出超差项 | 由各表自动汇总 |
| 1 Method | 仪器类型（optical CMM / vision measuring machine）、测量点数、不确定度 U (k = 2)、温度条件 | 一段 ≤ 3 行 |
| 2 Pattern geometry | 表：Feature · Nominal (mm) · Measured (mm) · Deviation (µm) · Tolerance (µm) · Result | 行：Square pitch X、Square pitch Y、Pattern width、Pattern height、Diagonal 1、Diagonal 2、Orthogonality (°)、Max single-feature deviation（n 个角点的最大值）、RMS deviation；陶瓷按 µm，复合板按 mm |
| 3 Flatness | 表：Measured flatness (µm) · Tolerance · Method (n points) · Result | |
| 4 Visual | 表：Edge chamfer · Surface defects (scratches/pinholes in pattern area) · Print/edge definition · Marking legibility (label line, X/Y arrows, SN) · Result | 每项 PASS/FAIL/N/A |

### 第 2 页

| 区块 | 内容 |
|---|---|
| 5 Feature map | 板面示意图（图案渲染 + 坐标系 + 测点编号），右上角图例：红 X 向右、绿 Y 向下、原点左上外角 |
| 6 Measured coordinates | 说明：完整角点坐标在随附 CSV（CT-CSV-<sn>.csv，n 行），字段 id, x_nom, y_nom, x_meas, y_meas, dx, dy；这里只列前 10 行作预览 |
| 7 Statement | `The item identified above meets the specifications of datasheet <code> rev <X> at the time of inspection. This is an inspection report issued by Calib.Tools; it is not an accredited calibration certificate. An ILAC-MRA certificate issued by an accredited third-party laboratory is available as SVC-X-CERT-ILAC.` |
| 8 Traceability | 仪器校准证书编号与有效期；参考量块/玻璃尺编号；`Raw data retained for 10 years under this serial number.` |
| 签名 + 章 + 二维码 | 见第 1 节 |

**措辞规则**：不写 "calibrated"（板不是被校准，是被测量）；"inspection" 一词贯穿；PENDING 时 Statement 改为 `Measurement data pending; this report will be re-issued as Rev B.`

## 3. CT-DS · 产品数据表（每家族×材质）

**目的**：工程师选型和写进设备文档；采购比价。**来源**：`docs/datasheets/CT-DS-<FFF>-<M>.md`。

| 页 | 区块 | 字段 |
|---|---|---|
| 1 | 标题 + 一句定位 | 家族 + 材质；首句 ≤ 25 词（同产品页定位句） |
| 1 | 产品图 | 实拍或渲染（标注 Rendering 由你定）+ 坐标系示意 |
| 1 | Ordering 表 | Part number · Size W × H (mm) · Squares (rows × cols) · Square / marker (mm) · Dictionary options · Corners · Markers · Weight (kg) · Price (EUR, excl. VAT)（网站版带价，印刷版不带） |
| 1 | Key specs 条 | Accuracy · Substrate / thickness · Sizes · Flatness（与产品页关键参数条一致） |
| 2 | Specifications · Geometry | Feature position accuracy（条件 20 °C）· Edge definition · Orthogonality · Start ID / placement 规则（OpenCV ≥ 4.6） |
| 2 | Specifications · Physical | Substrate · Pattern/ink · Thickness · Flatness · Surface (Ra) · Edges · Weight · Mounting (holes / none, fixture) |
| 2 | Specifications · Environment | Operating temp · Storage temp · Thermal expansion · Humidity · Chemical resistance · UV / outdoor life · Cleaning |
| 3 | Deliverables | In the box（板、箱、报告）· Files（.opencv.json, .kalibr.yaml, .ros2.yaml, .halcon.descr, .dxf, measured CSV）· Marking on board（label line 内容、X/Y arrows、SN）· Lead time · Options（fixture、ILAC certificate、custom NRE） |
| 3 | Compatibility | OpenCV / Kalibr / HALCON / MATLAB / ROS 2 各一行：版本与注意事项 |
| 3 | Drawing | 外形尺寸图（W、H、t、白边、图案净尺寸、倒角、孔位）；DXF 下载地址 |
| 4 | Compliance & customs | RoHS · REACH（如有）· HS 9031 80 · Country of origin（**按事实**）· Packaging · Fragile |
| 4 | Revision history | Rev · Date · Change |
| 4 | Disclaimer | `Values are nominal unless stated as measured; per-unit values are in the inspection report CT-IR-<SN>.` |

## 13. CT-QR · 标定质量报告（工具 T6）

**免费诊断版**（1 页）：Summary 评分（A–D）· 重投影误差（RMS、最大、分布直方图）· 覆盖热力图（图像平面）· 三条建议。

| 区块 | 内容 |
|---|---|
| 输入 | 相机型号（用户填）、图像数、靶标型号/SN（如用我们的板，自动带入 IR 数据）、软件与版本 |
| 内参 | fx fy cx cy、畸变系数、各自标准差与相关系数矩阵（热力图） |
| 每张图 | 重投影误差、姿态、是否被剔除 |
| 不确定度 | 内参不确定度传播到典型工作距离的 mm 误差 |
| 缺失视角 | 建议补拍的姿态清单（图示） |
| 靶标贡献 | 若 SN 已知：靶标实测偏差对结果的贡献上限 |
| 声明 | `Computed from user-supplied data; Calib.Tools has not verified the images or the camera.` |
