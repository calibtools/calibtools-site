## 需要你决定或确认的事项

**主体与税务**
- 法律主体名称、地址、USt-IdNr.
- 公司注册前以个人主体开票的说明。
- 欧盟 B2B 免税措辞、供货证明流程：请税务顾问确认。注意 §13b 反向征收只适用于服务，商品用的是 §4 Nr. 1b / §6a 免税。

**检验与签发**
- 检验地点的写法。
- 签字人姓名与职务。
- 检验章上的序列号写法。

**材料与合规**
- 图案工艺、表面粗糙度、热膨胀系数、温湿度范围。
- RoHS 是否适用于无源陶瓷板。
- REACH 供应商声明。
- 原产国。

**软件兼容性**
- HALCON、MATLAB（R2024a 起的 ChArUco 函数）、ROS 2 camera_calibration 的具体版本需核实。
- Kalibr 没有原生 ChArUco 支持，`.kalibr.yaml` 的描述方式需要你定。

**第三方证书**
- 合作实验室名称、认可机构与编号、证书页数。

**服务政策**
- 保修期限、退货 / RMA 流程。
- 复检流程与周期（样张暂按 24 / 12 / 6 个月）。
- CoC 是否默认随货。
- CC 随货还是后寄（样张为后寄）。

**工具阈值**
- 检测检查的阈值：角点 ≥ 95 %，对比度 ≥ 100，清晰度 ≥ 150。
- 标定质量报告的 A–D 评级规则。

**价格**
- 报价单与发票中的价格均为示意价。

**缺失文件**
- `CT-IR-000312`、`CT-CSV-000312`、`CT-AN-001` 在文件包中是占位文件。补齐后重新运行 `build_fm.py`，即可刷新哈希值。
